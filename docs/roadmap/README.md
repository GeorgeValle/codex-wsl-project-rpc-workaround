# Stable roadmap

Blocks and Subdivisions are stable planning identities. Pull Requests are
implementation units and historical delivery evidence only; closing, replacing,
splitting, or repeating a PR does not change roadmap identity. A Subdivision
may require one or more PRs.

## Block 4 — Hardening

- **Subdivision 4.1 — Validation and path safety**
- **Subdivision 4.2 — Failure recovery and diagnostics**
- **Subdivision 4.3 — User-facing ergonomics**

The approved roadmap excludes `project/move`, `project/delete`, and all
destructive operations. Such operations require a separately proposed and
explicitly approved future Block.
