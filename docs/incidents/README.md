# Incident evidence records

This directory records public evidence about incidents that constrain the
repository's design. Incident reports are evidence, not protocol specifications;
protocol claims remain governed by the pinned public OpenAI sources in
[`docs/protocol`](../protocol/).

Records distinguish observations, direct reproductions, static inspection,
maintainer acknowledgement, repository inference, and unresolved hypotheses.
They use public permalinks and sanitized examples; private mail, credentials,
user state, and personal paths are excluded.

An incident record does **not** authorize capability, real RPC, Codex-state
access, or mutation. Authorization remains deny-by-default under the
[requirements](../../projects-requirements.md) and roadmap.
